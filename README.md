# HR Data Analytics Dashboard

An interactive HR Data Analytics dashboard built using Microsoft Power BI to analyze employee data and generate meaningful insights for better workforce decision-making.

The project focuses on transforming HR data into interactive visualizations and actionable insights using Power BI reports, data modeling, and analytics.

---

## Project Overview

Human Resource departments deal with large amounts of employee data, including information about workforce composition, employee demographics, job roles, compensation, performance, and retention.

This project uses Power BI to analyze HR data and present important workforce insights through an interactive dashboard.

The dashboard helps HR teams and decision-makers understand employee trends, identify patterns, and make data-driven decisions.

---

## Objectives

The main objectives of this project are:

* Analyze employee-related data using Power BI
* Identify important HR trends and patterns
* Create meaningful KPIs for workforce analysis
* Build interactive and easy-to-understand dashboards
* Apply data modeling and visualization techniques
* Convert raw HR data into actionable business insights

---

## Key Features

### Workforce Analysis

Analyze the overall employee population and understand workforce distribution.

### HR KPIs

Track important HR metrics through interactive KPI cards and visualizations.

### Employee Analysis

Explore employee information across different categories such as departments, roles, and other relevant attributes.

### Interactive Visualizations

Use Power BI charts, graphs, tables, and filters to explore the data.

### Dynamic Filtering

Users can interact with the dashboard using filters and slicers to analyze specific segments of the workforce.

### Data Modeling

The project includes a dedicated Power BI Semantic Model, allowing the report to work with structured and organized data.

## Getting Started

### Prerequisites

You will need:

* Microsoft Power BI Desktop
* A Windows environment capable of running Power BI Desktop
* The project files from this repository

### Clone the Repository

```bash
git clone https://github.com/sukrutha705/HR_DataAnalytics.git
```

### Open the Project

Open the cloned project directory and open:

```text
HR_ANALYTICS.pbip
```

using Power BI Desktop.

### Explore the Dashboard

Once opened, you can:

* Navigate between report pages
* Interact with filters and slicers
* Explore visualizations
* Inspect the data model
* Analyze the available HR metrics
